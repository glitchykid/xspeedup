# X SpeedUp 0.4.0

- Compact dark minimalist interface, Gunmetal surfaces, restrained sage accents and original generated icons; all six languages retained.
- Select-all checkboxes and action buttons that stay visible while scrolling.
- Choose a folder or all local drives. Empty-folder scanning automatically continues to completion, with no 5,000-result cutoff and paginated results.
- Balanced Game Mode: Windows Game Mode, selected optional services and normal app-close requests, with persistent restoration.
- Original GPU geometry/shader workload, GPU readback checks, frame-time statistics and optional CPU/RAM testing.
- Experimental capability-based NVIDIA core/VRAM clock scan with small bounded increments, temperature/heartbeat monitoring, independent recovery and original-offset restoration after the scan.

Automatic clock control currently requires one supported NVIDIA GPU, a matching hardware renderer, a temperature sensor and administrator rights. CPU/system RAM and other GPU clock-control adapters are not implemented. Tested values are reported; they are not applied permanently. Short tests do not prove complete stability, and live clock writes still require acceptance testing on dedicated hardware.

Windows 10/11 x64. The unsigned installer includes the .NET runtime. Check its SHA-256 digest against `SHA256SUMS.txt`. File/folder deletion is permanent; registry, service, gaming and tuning recovery are stored locally in History.
