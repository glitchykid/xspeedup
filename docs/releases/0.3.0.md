# X SpeedUp 0.3.0

- New Glass Morphism interface in light and dark themes, with original generated illustrations and icons.
- Russian, English, Ukrainian, Korean, Japanese and Simplified Chinese interface and confirmation dialogs.
- Fixed active navigation hover colors.
- Extended registry cleanup: Run/RunOnce, stale App Paths, qualifying non-MSI Uninstall leftovers, and empty application keys. Typed backups and conflict-aware restore are included.
- Empty-folder scanning across available local fixed/removable drives, with incremental continuation and explicit selection.
- Release a selected application's working set without closing it. Memory can return and faster performance is not guaranteed.

Download **X-SpeedUp-Setup-0.3.0.exe** for Windows 10/11 x64. Runtime dependencies are included. **SHA256SUMS.txt** records the published installer checksum.

The installer is unsigned. File/folder deletion is permanent. Registry and service changes are backed up locally. HKLM/service changes require administrator rights. Protected/system directories and ambiguous registry candidates are excluded; review every selection. Technical diagnostics retain their original language.

Automated mutations are tested using isolated filesystem fixtures and in-memory OS adapters. Real registry transaction writes/restoration, administrator service changes and working-set trimming still need acceptance testing in a disposable Windows VM.
