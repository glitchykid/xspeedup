# X SpeedUp 0.2.0

This release introduces a brutalist interface with light and dark themes across every screen.

- Sharp rectangular panels, bold typography, visible borders, solid accent colors, and hard offset shadows.
- A persistent light/dark theme selector available throughout the app. On first launch, the theme follows the Windows preference.
- More legible controls, selected states, keyboard focus, and reduced-motion support.
- The existing file cleanup, startup registry review, service profiles, application inspection, and recovery workflows remain available.

Download **X SpeedUp Setup 0.2.0.exe** for Windows 10/11 x64. Node.js and .NET do not need to be installed separately. **SHA256SUMS.txt** contains the installer checksum.

The installer is unsigned. Run the app as administrator only when changing or restoring service startup modes. Review every maintenance action before confirming it. File cleanup is permanent; registry and service settings have local backups.
