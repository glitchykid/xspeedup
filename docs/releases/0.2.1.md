# X SpeedUp 0.2.1

Brutalist Windows maintenance interface with persistent light and dark themes across all six screens.

- Bold typography, square panels, strong borders, solid accents, and hard shadows.
- Theme selection follows Windows on first launch and remembers your explicit choice.
- File cleanup, startup registry review, optional service profiles, application inspection, and recovery history.
- This patch aligns the installer filename with the filename recorded in the published SHA-256 checksum.

Download **X-SpeedUp-Setup-0.2.1.exe** for Windows 10/11 x64. Node.js and .NET do not need to be installed separately. **SHA256SUMS.txt** contains the checksum of the published installer.

The installer is unsigned. Run the app as administrator only when changing or restoring service startup modes. Review every maintenance action before confirming it. File cleanup is permanent; registry and service settings have local backups.
