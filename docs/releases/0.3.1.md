# X SpeedUp 0.3.1

Includes the Glass Morphism redesign with both themes, generated illustrations/icons, six interface languages, expanded registry review, empty-folder scanning and application memory release introduced in 0.3.0.

This patch retains the selected process handle throughout memory eligibility/identity checks and working-set trimming, so an exiting application's process ID cannot redirect the action to a new process.

Download **X-SpeedUp-Setup-0.3.1.exe** for Windows 10/11 x64. Runtime dependencies are included. **SHA256SUMS.txt** contains the published installer checksum.

The installer is unsigned. File/folder deletion is permanent; registry and service changes have local backups. Memory release trims a selected application's working set without closing it, can slow subsequent page access, and does not guarantee improved performance. HKLM/service changes require administrator rights. Technical diagnostics retain their original language.

Automated mutations use isolated files and in-memory OS adapters. Native registry transaction writes/restoration, administrator service changes and OS working-set trimming still require disposable-VM acceptance testing.
