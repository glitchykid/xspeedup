# Generated icons for 0.4.0

The final design follows the latest brief: compact dark minimalism, Gunmetal #2A3439 as the primary color, restrained sage accents and no blue chromatic accents. Earlier cyberpunk backgrounds and glass illustrations are not shipped.

The icons were edited with the built-in image generation tool on 2026-09-28. No API/CLI fallback was used. Generated PNGs retain transparent exteriors and are packaged locally, without remote requests.
